# Brick Breaker

A simple Brick Breaker game developed using Python and Pygame.

## Features
- Paddle and ball gameplay
- Brick collision detection
- Score tracking
- Lives system
- Easy, Medium, and Hard difficulty modes
- Replay option after winning or losing
- Sound effects for:
  - Paddle hit
  - Brick break
  - Game over

## Requirements
- Python 3.x
- Pygame

## Run the Game

Install pygame:

```bash
pip install pygame
```

Run the game:

```bash
python main.py
```
